# Penn Action metadata

`penn_action_schema.json` was generated by `scripts/inspect_labels.py`. It holds field
names, the train/test codes, class order and joint count, not coordinates, and every run
checks the label files against it.

## What the labels contain (checked Nov 1, 2026)

Source: official archive `https://www.cis.upenn.edu/~kostas/Penn_Action.tar.gz`, labels only,
downloaded with `scripts/download_data.py`.

Command:

```bash
python scripts/inspect_labels.py --data-root data/Penn_Action \
  --fields '{"x":"x","y":"y","visibility":"visibility","action":"action","split":"train","nframes":"nframes","dimensions":"dimensions"}' \
  --train-value 1 --test-value -1 --dimensions-order hwt
```

- **Fields:** every file has `action`, `pose`, `x`, `y`, `visibility`, `train`, `bbox`,
  `dimensions`, `nframes`. `x`, `y`, `visibility` are time-first `[nframes, 13]`.
- **Clips and split:** 2,326 clips, 15 classes, 13 joints. `train` = 1 for 1,258 clips and
  −1 for 1,068 clips, matching the split used by CascadeFormer.
- **Class names in the files:** `baseball_pitch, baseball_swing, bench_press, bowl,
  clean_and_jerk, golf_swing, jump_rope, jumping_jacks, pullup, pushup, situp, squat,
  strum_guitar, tennis_forehand, tennis_serve`. These differ from the spellings on the
  official web page; code uses the file values.
- **Clip length:** 18–663 frames; median 56, mean 70.4, quartiles 43 / 78.
- **Visibility:** 77.96% of joint-frames visible overall (**22.0% invisible**); train 78.1%,
  test 77.8%. By class it ranges from 59.4% (strum_guitar) to 96.8% (jumping_jacks). By
  joint index, 0 is most visible (93.0%) and indices 1–2 least (71.8%, 70.1%).
- **Per-clip invisible fraction (histogram, bins of 0.1):** 511, 588, 575, 358, 177, 63, 45,
  7, 1, 1.
- **Some hidden coordinates are placeholders:** of 469,501 hidden joint-frames, 187,326
  (39.9%) hold a near-corner value with x = y ≤ 5 px, most often 0.75 or 0.667. All of them
  belong to joints that are never visible in their clip, and no visible joint-frame holds
  such a value (checked separately on Nov 6, 2026). Also, 0.006% are exactly (0, 0) and
  0.0002% fall outside the image. For hidden joints with visible frames on both sides
  (127,886 joint-frames, none with a near-corner value), the median distance to the linearly
  interpolated position is 4.3 px (mean 8.3, 75th percentile 9.9). Our preprocessing never
  reads stored hidden coordinates: it interpolates from visible frames and sets
  never-visible joints to zero.
- **Bounding boxes:** clips 1154 and 1865 have one fewer `bbox` row than `nframes`, so
  `bbox` is left out of the schema and the inside-bbox diagnostic is not computed. Training
  never uses bounding boxes.
- **Never-visible clip:** clip 1516 (pushup, official train, 68 frames) has no visible joint
  in any frame. It cannot be normalized and would be all zeros after imputation, so
  training excludes official-train clips with no visible joint and records their IDs in
  each run's `metadata.json` (`excluded_train_ids`). No validation or test clip is affected.
- **Viewpoint:** the `pose` field is a short string per clip, presumably the camera view;
  its values have not been tabulated and the loader does not read it.

## Validation split

`splits/val_ids.txt` (Nov 1, 2026) holds 253 clips, about 20% of each class's official
training clips, drawn with seed 42. That leaves 1,005 training clips, or 1,004 after
excluding clip 1516. The labels have no source-video or performer ID, so the split cannot
be grouped by video.
